A LITTLE ABOUT SIDECAR

Good music.
Better company.

Sidecar is a small, independent experiment in listening together. A room, a shared queue, and a link for your friends.

Start a room ↗

One room. Everyone brings something.

Open a room in your desktop browser, enter a nickname, and add a public SoundCloud track. Send the invite link to your friends. The host controls play, pause, seeking, and skipping; everyone can add to the queue.

Each listener plays audio directly through SoundCloud’s official embedded player. Sidecar sends room and playback updates between browsers. It does not download, store, or broadcast the music.

A prototype with a few limits.

  • Playback alignment is experimental. Buffering, advertisements, browser restrictions, and different devices can interrupt synchronization. There is no measured latency guarantee.
  • Use public, embeddable track links. Some tracks may be restricted by region, subscription, or the uploader.
  • You may need to enable listening before your browser permits audio. Headphones work best if listeners are near each other.
  • Rooms disappear when the server restarts. Anyone with a room link can join, so share it within your group.
  • This is a desktop web experience. It does not control SoundCloud’s native app; mobile and locked-screen playback are unverified.

Small by design. Open by nature.

Sidecar’s source code is MIT licensed and designed to run on a single Node.js server. The project includes setup instructions and Docker packaging for people who want to run their own copy. No Sidecar account or SoundCloud API key is needed for this prototype.

The code license covers Sidecar’s software. It does not grant rights to music, artwork, trademarks, or SoundCloud’s services.

Independent of SoundCloud.

Sidecar is not affiliated with or endorsed by SoundCloud. SoundCloud’s player and widget terms restrict using its content in separate content services without prior written consent. Its API terms contain additional restrictions.

Using an official embedded player does not by itself establish permission to operate a listening-party service. Clarify your intended use with SoundCloud before public hosting.
